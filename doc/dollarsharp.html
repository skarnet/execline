The dollarsharp program

dollarsharp prints the number of arguments it is called with.

Interface 

     dollarsharp [ args ]
  • dollarsharp reads the number of arguments it is given, then prints this number on stdout.
  • It then exits 0.

    • Notes

    • A use case for dollarsharp is e.g. after calling an elglob -0 command, to check how many results the globbing returned.
